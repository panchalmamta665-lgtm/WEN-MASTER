WIN MASTER - Android Project

इस ZIP में Android ऐप का source project और गेम HTML शामिल है।
यह अभी तैयार APK नहीं है।

APK बनाने के लिए:
1. इस ZIP को कंप्यूटर पर extract करें।
2. Android Studio में इस folder को Open करें।
3. Gradle sync पूरा होने दें।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
5. APK app/build/outputs/apk/debug/app-debug.apk में मिलेगा।

ध्यान दें:
- इस डेमो में Spin Wheel, Ludo Mini और 3 Patti card demo हैं।
- पॉइंट्स केवल डिवाइस में सेव होते हैं।
- असली पैसे, जमा, निकासी या cash rewards नहीं हैं।
- Play Store पर डालने से पहले testing, privacy policy, app icon और Google Play की मौजूदा policies की जाँच जरूरी है।
